Тестовое задание для AQA стажёра в компании учи

## Подготовка к работе

Для начала работы убедитесь, что у вас установлены [node.js + npm](https://nodejs.org/en/download)

Установите зависимости проекта, выполнив команду:

```shell
npm ci
```

## Запуск тестов

Запустите тесты с помощью команды:

```shell
npx playwright test
```

---

## Выполненные исправления

В рамках задания исправлены две ошибки в автотестах виджета поддержки Учи.ру.

**1. Получение популярных статей**

В методе `getPopularArticles()` убран вызов `.all()`. Теперь метод возвращает `Locator`, а первый элемент списка выбирается непосредственно в тесте с помощью `.first()`.

Это позволяет использовать встроенное ожидание Playwright вместо получения массива элементов до их появления.

**2. Селектор кнопки «Написать нам»**

Слишком общий селектор `[class^=btn]` заменён на `[data-test="button_feedback_form"]`, чтобы однозначно находить нужную кнопку.

## GitHub Actions

Настроен автоматический запуск тестов Playwright при отправке изменений в ветку `master` и при создании или обновлении pull request в эту ветку.

Workflow находится в `.github/workflows/playwright.yml`.

После выполнения тестов HTML-отчёт сохраняется как артефакт `playwright-report` на 7 дней, в том числе при неуспешном запуске.

Посмотреть результаты и скачать отчёт можно в разделе **Actions → нужный запуск → Artifacts**.

## Известное ограничение

При тестировании обнаружено нестабильное появление виджета поддержки на главной странице Учи.ру.

В некоторых запусках кнопка `[data-test="openWidget"]` отсутствует в DOM, и тест завершается по тайм-ауту 30 секунд
